## ClippingAlpha

[ClippingAlpha](https://clippingalpha.com) ranks live paid clipping, UGC, logo and music campaigns from Content Rewards, Promote.fun, Clipster, Clipstake, Vyro and Evangelist by the Alpha Score, with pay per 1,000 views, budget left, run-out forecasts, briefs and the best moments to clip. The Alpha Score is never for sale. ClippingAlpha is operated by Momentist, Inc.

- [clippingalpha-mcp](https://github.com/ClippingAlpha/clippingalpha-mcp): the hosted MCP server for Claude, ChatGPT, Cursor and other AI assistants
- [clipping-market-data](https://github.com/ClippingAlpha/clipping-market-data): an open daily dataset of the clipping market, CC BY 4.0
- [awesome-clipping](https://github.com/ClippingAlpha/awesome-clipping): a curated list of clipping platforms, tools and guides
- [How the Alpha Score works](https://clippingalpha.com/how-we-rank)
